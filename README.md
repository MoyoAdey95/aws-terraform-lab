# aws-terraform-lab

A container platform on AWS, rebuilt from a stack I first ran on GCP. The application is deliberately trivial. The question the repo answers is whether the architecture transfers, and what differs on AWS as opposed to GCP.

Region is eu-west-2. The 12 month free tier on this account has expired, so everything here is billable. The working pattern is build, capture evidence, destroy in the same session.

Status: in progress.
